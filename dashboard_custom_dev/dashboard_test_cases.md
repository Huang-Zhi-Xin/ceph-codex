## 1. 执行说明

- 本清单按模块顺序执行。
- 若当前环境缺少后端依赖，结论记为 `Blocked`，同时确认空态、提示文案、禁用态是否正确。
- 若执行新增类操作，完成后应删除测试数据。
- 测试数据命名统一使用 `kx-test-<YYYYMMDD>-<序号>`。
