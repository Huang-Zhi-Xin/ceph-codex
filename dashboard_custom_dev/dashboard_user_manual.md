# KX Storage 分布式存储管理系统用户使用手册

## 1. 系统简介

KX Storage 分布式存储管理系统基于 Ceph Dashboard 二次开发，提供以下能力：

- 集群状态监控
- 对象存储、块存储、文件存储统一管理
- 用户与角色管理
- 服务编排与升级管理
- 日志、告警等可观测能力

本文档面向平台管理员与运维人员。

## 2. 登录与界面说明

### 2.1 登录入口

通过浏览器访问 Dashboard 地址，例如：

```text
https://192.168.100.111:8443
```

输入管理员用户名和密码后登录系统。

### 2.2 登录页说明

登录页包含：

- KX Storage 品牌图标
- 系统名称
- 用户名与密码输入框
- 语言切换入口

### 2.3 顶部区域说明

顶部区域主要包括：

- 语言切换
- 通知入口
- 帮助入口
- 管理入口
- 当前用户入口

帮助菜单保留：

- `API`
- `About`

## 3. 首页与导航说明

### 3.1 首页

首页用于查看集群的核心状态信息，包括：

- 集群健康状态
- 容量使用情况
- 性能概览
- 告警和通知摘要

### 3.2 左侧导航

左侧导航按模块组织功能，常见菜单如下：

- 仪表盘
- 多集群
- 集群
- 块设备
- 对象存储
- 文件存储
- 可观测性
- 管理

## 4. 集群管理

### 4.1 集群视图

在“集群”菜单中，可以查看：

- 存储池
- 主机
- OSD
- 物理磁盘
- CRUSH 图
- 监视器

### 4.2 主机管理

主机页面可用于：

- 查看主机信息
- 查看网络地址
- 查看主机关联服务
- 执行主机相关维护操作

### 4.3 OSD 与磁盘

OSD 与物理磁盘页面用于：

- 查看 OSD 状态
- 查看磁盘库存
- 识别可用于扩容的设备
- 分析存储节点状态

## 5. 块存储管理

块存储模块用于管理 RBD、iSCSI、NVMe/TCP 等能力。

常见操作包括：

- 创建与查看 RBD 镜像
- 配置镜像复制
- 查看块设备性能
- 管理 NVMe/TCP 相关资源

适用场景：

- 虚拟机磁盘
- 数据库块设备
- 高性能块存储业务

## 6. 对象存储管理

对象存储模块用于管理 RGW 相关资源。

可管理对象包括：

- 用户
- 存储桶
- 主题
- 分层
- 多站点
- 网关
- 配置

常见操作：

- 创建对象存储用户
- 创建和管理存储桶
- 管理对象存储复制与多站点结构

## 7. 文件存储管理

文件存储模块用于管理 CephFS、NFS、SMB。

主要能力：

- 查看与管理文件系统
- 管理 NFS 导出
- 管理 SMB 共享
- 查看快照调度
- 管理子卷与子卷组

适用场景：

- 共享文件目录
- NFS 服务
- SMB 文件共享服务

## 8. 可观测性

可观测性模块包括：

- 日志
- 告警

主要用途：

- 查看集群运行日志
- 查看当前告警信息
- 配合首页与通知栏定位异常

出现异常时，建议优先检查：

- 首页健康状态
- 可观测性中的日志
- 可观测性中的告警

## 9. 管理功能

管理模块一般用于平台级操作，包括：

- 服务
- 升级
- Ceph 用户
- Manager 模块
- 配置

### 9.1 服务管理

服务管理页面可用于查看并管理集群中的服务编排信息，例如：

- 服务类型
- 服务部署状态
- 服务相关参数

### 9.2 升级

升级页面用于查看：

- 当前版本
- 可升级版本
- 升级状态
- 升级日志

执行升级前，应确认：

- 集群健康状态正常
- 已完成当前配置备份
- 已明确回滚方案

## 10. 用户与角色管理

### 10.1 用户管理

可以在用户管理中：

- 创建用户
- 修改用户
- 删除用户
- 查看用户角色

### 10.2 角色管理

角色用于定义用户可访问的功能范围。

使用建议：

- 管理员账号使用高权限角色
- 日常运维账号使用受限角色
- 按职责最小化授权

## 11. 语言切换

当前系统保留两种语言：

- 中文（简体）
- English

默认语言可配置为中文。

如果切换语言后界面未及时刷新：

- 重新加载页面
- 清理浏览器缓存
- 清理 `cd-lang` cookie

## 12. 常见运维动作

### 12.1 检查 Dashboard 是否正常

重点检查：

- 页面是否可登录
- 首页是否能正常显示状态卡片
- 左侧菜单是否完整
- About 弹窗是否正常打开

### 12.2 升级后检查

升级或更新后，建议按顺序检查：

- 登录页品牌与图标
- 左侧菜单汉化
- 顶部菜单
- About 弹窗
- 首页状态数据
- 日志与告警页面

### 12.3 页面异常时的基础排查

优先排查：

- 浏览器缓存
- 当前语言 cookie
- Dashboard 服务状态
- `mgr` 服务是否切换到正确版本

## 13. 常见告警与注意事项

### 13.1 HEALTH_WARN

当集群显示 `HEALTH_WARN` 时，需要结合具体告警项分析。

常见原因：

- OSD 数量不足
- 存储池副本数与当前集群规模不匹配
- 服务未完全部署

### 13.2 单机场景说明

如果当前是单机测试集群：

- Dashboard 可以正常展示，但业务能力有限
- 一些高可用与副本相关告警可能是预期现象

### 13.3 数据安全说明

涉及以下操作时需要谨慎：

- 创建 OSD
- 删除存储池
- 删除文件系统
- 删除 RBD 镜像
- 修改关键集群配置

这些操作可能直接影响现有数据或业务访问。
