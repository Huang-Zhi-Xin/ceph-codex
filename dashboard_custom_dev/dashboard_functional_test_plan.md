# KX Storage Dashboard 汉化后功能验收测试方案

## 1. 文档目的

本文档用于指导 KX Storage Dashboard 汉化完成后的前台功能验收，覆盖：

- 中文化与品牌定制结果确认
- 核心页面可达性与基础交互验证
- 高风险功能关键路径验证
- 空态、禁用态、异常态与权限态验证

执行方式为“测试人员操作页面，远程协同判定结果”。默认允许创建少量测试资源，并在测试结束后统一清理。

## 2. 测试范围

本轮按完整产品功能制定计划，实际执行时拆分为两层。

### 2.1 第一层：全站基础冒烟

- 登录页
- 顶部区域
- 首页/仪表盘
- 左侧导航
- 一级菜单可达性
- 语言切换
- 品牌与 About 信息

### 2.2 第二层：模块深度验收

- 多集群
- 集群
- 块存储
- 对象存储
- 文件存储
- 可观测性
- 用户与权限

## 3. 测试策略

### 3.1 分层执行

- 第一天执行基础冒烟与汉化专项。
- 第二天起按模块进行深测。
- 每完成一个模块即记录通过项、失败项、阻塞项。

### 3.2 缺陷分级

- `P0`：无法登录、白屏、核心功能不可用
- `P1`：关键流程失败、严重错译、权限错乱
- `P2`：文案错误、布局错位、提示不一致
- `P3`：低频瑕疵、样式细节问题

### 3.3 结果结论

- `Pass`：结果符合预期
- `Fail`：结果不符合预期，且可复现
- `Blocked`：因环境、权限、依赖服务未启用导致无法完成闭环

## 4. 测试前准备

### 4.1 账号准备

- 管理员账号：覆盖全部菜单与写操作
- 受限账号：用于验证菜单裁剪、按钮权限、403 与禁用态

### 4.2 浏览器准备

- Chrome 最新版
- Edge 或 Firefox 二选一

### 4.3 每轮开始前清理

- 浏览器缓存
- `cd-lang` cookie
- 无痕窗口复测登录页与首页

### 4.4 测试数据规范

统一使用：

```text
kx-test-<YYYYMMDD>-<序号>
```

示例：

```text
kx-test-20260325-01
```

## 5. 模块测试重点

### 5.1 登录与公共区域

- 登录页显示 `KX Storage` 品牌信息
- Logo、浏览器标题、favicon 正确
- 用户名、密码、登录按钮、语言切换显示正常
- 帮助菜单仅保留约定项目
- About 弹窗品牌、版权、版本信息符合定制要求

### 5.2 首页与导航

- 集群健康、容量、性能卡片正常显示
- 图表、悬浮提示、刷新、时间范围切换正常
- 一级菜单顺序、命名、展开收起正常
- 面包屑、页面标题、页签标题一致
- 页面切换后左侧导航高亮正确

### 5.3 集群

覆盖：

- `Pools`
- `Hosts`
- `OSD`
- `Inventory`
- `CRUSH Map`
- `Monitor`
- `Configuration`
- `Services`
- `Manager Modules`
- `Upgrade`
- `Ceph Users`

每个列表页统一检查：

- 页面可打开
- 列表可加载
- 搜索、筛选、排序、分页正常
- 行详情、详情页、状态标签、时间格式正常

### 5.4 块存储

覆盖：

- `RBD`
- `Namespaces`
- `Trash`
- `Performance`
- `Mirroring`
- `iSCSI`
- `NVMe-oF`

关键路径：

- 创建镜像
- 查看详情
- 编辑基础属性
- 删除或移入回收站
- 恢复或清理

### 5.5 对象存储

覆盖：

- `Overview`
- `Daemon`
- `User`
- `Bucket`
- `Topic`
- `Tiering`
- `Multisite`
- `Configuration`

关键路径：

- 创建 RGW 用户
- 创建 Bucket
- 查看详情
- 编辑
- 删除

### 5.6 文件存储

覆盖：

- `CephFS`
- `Subvolume Group`
- `Subvolume`
- `Snapshot Schedule`
- `NFS`
- `SMB`

关键路径：

- 查看文件系统
- 创建子卷组/子卷
- 验证快照调度表单校验
- 验证 NFS/SMB 的列表、详情、表单可达性

### 5.7 可观测性

覆盖：

- `Logs`
- `Alerts`
- `Active Alerts`
- `Silences`

统一检查：

- 页面加载
- 严重级别标签
- 时间格式
- 筛选条件
- 详情信息
- 空态与计数逻辑

### 5.8 用户与权限

- 管理员账号可见全部预期菜单
- 受限账号仅可见授权菜单
- 直接访问无权限 URL 返回正确提示
- 用户创建、改密、角色绑定、退出登录流程正常

## 6. 汉化专项检查

### 6.1 问题类型

- 漏翻：仍显示英文原文
- 错译：术语不统一或语义错误
- 溢出：按钮、表头、标签、弹窗超宽或换行异常
- 混杂：同页中英混排、标点风格不一致

### 6.2 高风险位置

- 表格操作列按钮
- 弹窗标题与确认按钮
- 危险操作提示
- 表单校验文案
- Tooltip
- 下拉选项
- 面包屑
- 通知消息
- 图表图例
- 状态标签
- 时间范围选择器

### 6.3 语言切换专项

- 中文切英文后，菜单、页面、弹窗、通知全部切换
- 刷新页面后语言保持
- 重新登录后语言保持
- 清除 `cd-lang` 后恢复默认语言

### 6.4 品牌专项

- 登录页品牌
- 浏览器标题
- favicon
- 帮助菜单
- About 弹窗

## 7. 异常与兼容性检查

### 7.1 异常场景

- 必填项不填
- 非法字符
- 重名资源
- 删除前置依赖未清理
- 后端模块未启用
- 会话过期后继续操作

### 7.2 前端表现要求

- 有明确错误提示
- 无白屏
- 无死循环 loading
- 无致命报错导致页面不可用
- 弹窗可正常关闭
- 页面能恢复继续操作

### 7.3 兼容性要求

- `1920x1080` 正常显示
- 常见笔记本分辨率正常显示
- 浏览器缩放 `90%`、`100%`、`125%` 下主要页面不破版

## 8. 验收标准

- `P0`、`P1` 缺陷为 `0`
- `P2` 缺陷允许存在，但需形成修复清单
- 所有一级菜单至少完成一次可达性验证
- 所有可写模块至少完成一条“新增到清理”的闭环流程
- 汉化专项中不存在高频漏翻与品牌残留问题

## 9. 输出物要求

测试结果统一记录到测试记录表，字段固定为：

- `模块`
- `页面/功能`
- `前置条件`
- `操作步骤`
- `期望结果`
- `实际结果`
- `结论(Pass/Fail/Blocked)`
- `截图/备注`

建议测试期间同步维护缺陷清单，并标记严重级别、复现步骤、截图与环境信息。
